# Paket Tema Lengkap Nagari Lambah

Paket ini dibuat untuk mengganti/menambah halaman di:
C:\Users\ferri\nagari-lambah

## Cara pasang
1. Backup folder `app` dan `components` lama.
2. Salin folder `app`, `components`, dan `data` dari paket ini ke root project.
3. JANGAN hapus file `components/NavbarNagari.tsx` yang sekarang sudah berfungsi.
4. Jika Windows bertanya overwrite file halaman, pilih Replace untuk halaman yang ingin memakai tema baru.
5. Pastikan foto Ferri ada di:
   public\image\perangkat\ferri-dharma.png
6. Pastikan gambar sejarah ada di:
   public\image\sejarah-nagari-lambah.png
7. Jalankan:
   cd C:\Users\ferri\nagari-lambah
   npm run dev

## Tema
- Navbar: emas/caramel
- Judul: biru tua
- Aksen: emas
- Background: abu muda
- Card: putih rounded
- Footer: biru tua

## Penting
Paket ini TIDAK menyertakan NavbarNagari.tsx, sehingga Navbar aktif Anda tidak tertimpa.
